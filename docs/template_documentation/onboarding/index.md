# Using this GitHub template

Two pages, in order:

1. **[Template quick start](quick_start.md)** -- get a green build, so you know
   the toolchain is right before you change anything.
2. **[Customize and clean up](customize_repository.md)** -- rename the library,
   fill in the settings only you can know, and delete what you do not need.

Once you have worked through both, delete this whole section:

```bash
git rm -r docs/template_documentation
# then remove the "Template documentation" entry from nav in zensical.toml
```
